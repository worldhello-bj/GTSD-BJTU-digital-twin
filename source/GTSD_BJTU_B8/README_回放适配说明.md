# B8 源模型物理回放适配

本包保留原两节短车、每车一副转向架、A车单电机、原Z形受电弓及平行平衡杆，并加入四扇车辆检修门和两扇固定机柜门的真实求解回放。

两车布局源自原项目的专利类比配置，尚未证实为目标实机编组。源模型一致性不等于实机拓扑已经核实。质量、惯量、摩擦、气路和机械参数仍待标定。这是尚有明确简化的机械物理化原型，不能据此声称整机数字孪生已经完成或用于安全设计验证。

轮轨力由Python显式Hunt–Crossley/Coulomb柔性接触律计算，MuJoCo负责刚体/关节积分、原生盘片和弓网接触。完整物理输入包含配套Python力律和参数，单独打开XML并不能复现轮轨动力学；Blender只读取记录。

## 打开与播放

在 Blender 5.2 中打开 assets/GTSD_BJTU_B8_source_dynamics.blend，无需启用 Python 自动执行。

- B8_SOURCE_TOPOLOGY_REPLAY：制动基准的两车整体回放。
- B8_PANTOGRAPH_CLOSEUP：同一基准的受电弓近景。
- B8_ACCESS_INSPECTION_REPLAY：集成门检修工况，全车和六扇门来自同一求解。
- B8_ACCESS_CABINET_CLOSEUP：该集成工况的固定机柜近景。

时间轴采用30fps显示，空格播放。基准约10.00秒，门检修约10.00秒。检修场景第91帧附近可查看门开启状态；确切时刻以轨迹为准。切换场景后播放该场景独立工况，不能跨场景拼成一次连续试验。

关键帧全部由配套求解输出生成。修改力、质量、摩擦或气路参数需重新运行物理包并导入新轨迹；直接编辑 Blender 关键帧只改变显示。

## 机械显示与剩余简化

- 车体、构架、轮轴、制动盘、16个闸片和A车传动组件分别跟随求解刚体。
- Z形受电弓上下臂、平衡杆、肘部及滑板读取闭链求解结果；不沿用按时间设定升弓量。
- 气缸外观由实际连接点恢复。缸筒和活塞杆外壳不在显示适配器中另算质量或密封摩擦。
- 八个气囊及一次弹性支承外观随端点变形，金属端板随所属刚体。气囊力来自气体模型；一次支承力仍是等效关节，不是显示网格施力。
- 车钩两端分别读取两车连接点。未将原刚性转臂或反扭矩支架画成可伸缩机构；真实转臂逐铰点仍未完整实现。
- 柜门HMI图标和设备面板数字沿用静态源图形，不代表求解数据或实测采集；真实时序数据请读配套CSV/回放字段。
- 六扇门共84个原部件绑定到实际求解门体。门质量、弹簧、阻尼、闭锁和限位为明确假设；门把手没有独立机构，未求源网格对障碍物的碰撞。机柜支承固定在地面。
- 旧按点动画伸长的柜门接地跨接线未冒充实体电缆。拖缆的质量、弯曲、张力及碰撞未求解。旧ADD骨骼只带压力传感标记，不能当成真实阀芯。
- 压缩机、阀芯、风扇等剩余功能简化及其他缺口详见 reports/source_mechanism_coverage.json 和配套物理包覆盖表。该源审计形成于新增门模块之前；门的当前覆盖以本次六门报告为准。
- 轨道显示匹配XML的延长诊断试验范围，原项目实验室线路仍为10米。保留源踏面半径0.140米、轮缘0.149米；简化轮轨碰撞不能用于实机脱轨、磨耗或高保真接触预测。

两车质量/惯量、热过程、低黏着接触收敛及故障工况结论请读同批物理包；不要引用旧71坐标检查点的数值来评价本次结果。

## 重新生成

source/GTSD_BJTU_B7_detailed.blend 是只读输入。原B7交付未改写。先运行：

    blender --background --factory-startup --disable-autoexec --python scripts/import_b8_replay.py -- --trajectory inputs/final_replay.json --model-xml inputs/final_model.xml --final

再运行：

    blender --background --factory-startup --disable-autoexec --python scripts/append_b8_access_replay.py -- --trajectory inputs/access_replay.json --model-xml inputs/access_model.xml

第二步复用同一批网格，生成独立动作。重复生成会覆盖本包输出，手动修改后请先另存。只有已冻结并绑定哈希的轨迹才可标为正式输入；物理求解需使用配套物理包，而不是这些显示脚本。
