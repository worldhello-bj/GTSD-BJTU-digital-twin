# 制动回路身份：直接作用执行支路，不是列车制动主管

## 已有证据

北京交通大学2025BGC-172-2614《采购需求及技术要求》第1页明确“基础制动装置模组”，列出夹钳、制动盘和制动缸，并要求结构/动作原理支持实训。现有材料没有给出列车制动主管、分配阀/三通阀、辅助储风缸、紧急减压指令、弹簧储能执行器或原机完整气路图。

这不能证明原机没有自动制动；也不能证明本版的简化直接作用回路就是原机完整架构。此项须由原厂气路/控制图核实，不能把采购的基础制动机械结构说明扩写成已实现全列自动空气制动。

## 本版实际回路

有限储气罐 → 独立受控供气阀/止回边 → 制动执行压力腔 → 有效面积压力力 → 活塞/闸片 → 盘片摩擦 → 轮轴和车辆减速。

各压力腔另有独立正常排气口和故障泄漏口，通向大气。原文件名 brake_line_leak 的案例已经更准确改名为 brake_cylinder_branch_leak。

故障口实际上连接在“供气阀下游的执行压力腔”与大气之间，代表执行缸/下游支路破口；不是列车制动主管破裂。泄漏使该腔夹紧力下降，来自这个具体直接作用模型的因果链。

储气罐泄漏是另一个独立案例 reservoir_loss：供气源压力下降，而已有压力的执行腔受止回边影响可暂时保压。没有把储气、执行腔、受电弓腔或列车管压力混成同一个状态。

## 明确未实现

- 本版没有用列车制动主管减压去控制分配阀或紧急施闸。
- 没有假设“所有铁路制动系统漏气都会松闸”。
- 没有未获证据的弹簧制动/失压自动制动功能。
- 阀开度目前是控制输入，解了有限质量/流量/压力，但未逐阀芯求质量、弹簧和压力驱动。
- 若目标设备具有自动列车管制动或独立失压保护，须按其真实架构增加储风/分配/紧急支路，并另测断管自动制动，当前不能标已完成。

## 术语更新与旧检查点

旧检查点中的 brake_line_leak 仅是历史标识。应始终解释为执行缸下游支路漏气；不得将旧文件名翻译为“列车制动主管泄漏”。原数据保留未改，新的验收和用户说明采用明确名称。
