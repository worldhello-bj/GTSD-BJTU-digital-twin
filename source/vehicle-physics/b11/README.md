# B11 源线缆与柜门接地线等效物理

源模型八个曲线对象成为五条有质量的路线：三组地面回转供电线与车体服务线逐端连接，两组柜门保护接地线连接固定柜体和门叶。初始中心线、半径和连接位置来自只读源模型；运动由球铰、重力、地面/槽体接触与端点约束求解。源曲线坐标驱动不参与受力或回放。

**这是未标定的刚性链节近似。** 没有声称每一段都是实物杆件；密度、弯曲/扭转刚度、阻尼、摩擦、连接柔度均为推定。中心线初始形状假设无应力，不提供源动画中伸长 9.3% 的虚假张力结果。

## 力学与边界

- 基准 90 个刚性胶囊链节和 90 个三轴被动球铰，新增 270 个广义速度坐标；保留 B8 的 77 个车辆坐标。空间细化将长直段上限从 0.6 m 改为 0.3 m，弯曲处保留相同 3 mm 轮廓误差上限。
- 质量按 `ρ π r² L` 分配，转动惯量由同一胶囊几何编译；原 B8 所有显式惯量、质量和关节参数保持。新线缆总质量约 4.2898 kg，单独属于线缆系统。
- 被动角刚度为 `EI/L`，角阻尼为 `c_ref L_ref/L`；半径变化使用推定的 `EI ∝ r⁴`。这是各向同性弯曲/扭转代理，忽略轴向伸长、材料非线性及压力引起的软管几何变化。
- 一端固定，另一端通过三维软连接约束接入实际 `A_frame` 或柜门叶。车体会承受连接反力；切断连接只关闭约束，不写入机械位置或速度。
- 原生接触处理地面、线槽、非局部自身和不同路线间接触。相邻两节的胶囊端帽代表连续材料，排除局部重叠造成的虚假自接触；其余自接触保留。
- 端点和线缆接触的数值时间常数现为 0.5 ms；线槽底部、侧壁和地面明确使用一致的推定摩擦与接触设置。这些是代理求解参数，不是已测接头或材料曲线。
- B10 压缩机与风机模型继续接入气路，辅机安装质量/反力仍在独立固定台边界外。原气体质量状态 27、B9 平衡计量端口代理 51 保留。

## 验收与复现

依赖：Python 3.12、MuJoCo 3.3.7、NumPy 2.2.6 和 Matplotlib 3.10.8。Blender 5.2 用于显示，不是力学求解器。

```powershell
python source/vehicle-physics/b11/derive_b8_solver.py
python source/vehicle-physics/b11/test_cables.py
python source/vehicle-physics/b11/test_integration.py
python source/vehicle-physics/b11/simulate.py --case all
python source/vehicle-physics/b11/verify.py
python source/vehicle-physics/b11/report.py
python source/vehicle-physics/b11/live.py --headless --settle-s 0 --duration .02
```

求解脚本由哈希固定的 B8 源码通过逐项唯一匹配生成，冻结文件不修改。运行起止核对本次实际力学源码，结果身份同时绑定 XML、完整 CSV 和全部回放帧；仅执行 XML 不会得到 Python 的轮轨、气路与辅机力。

六组完整工况为正常制动、半时间步长、半空间链节上限、开关门、开关门半步长及三条供电线端点释放。每组自然沉降 6 s、观察 10 s。短程 `profile_*`/`prototype_*` 文件只用于开发诊断，不是验收工况。保留 B8 的 0.15 J 机械残差、0.05 N·s 车体动量残差、0.05 J 车辆气路耦合误差、1e-10 kg 质量误差与原步长阈值。

验收逐项核对实际工况配置、50/25 µs 步长、0.6/0.3 m 链节上限，以及 CSV、XML、回放和实际执行源码的关联。组件和回归报告也绑定测试源码及当前交互模块；回放检查完整时间窗、有限姿态和单位四元数。正式包采用源码清单，排除性能基准和短程诊断结果。

连接误差限为各路线半径的十分之一；刚性链节长度、内部铰接间隙和固定端漂移逐帧核对，阈值 2e-8 m。空间细化停车距离限值 5%，时间半步长仍使用 B8 的 2.5%。新增判据只约束数值代理，不能解释为连接器实物公差。

接触几何在每个原生积分位置记录，包括自然沉降和观察阶段，分别保存全部线缆接触的最大穿入/最小接触线缆半径。正式观察的每步几何范围要求该比值小于 1。另用实际 XML 在每个约 30 Hz 回放姿态独立重新计算位置阶段，核对原生刚体位置和采样接触，并检查完整积分峰值覆盖回放采样峰值。端点误差采用 100 Hz CSV 采样。软接触穿入是未标定的求解代理量，不是实物压缩量或碰撞精度；本次没有证明接触力峰值或连续体解收敛。

源参考曲线的中间服务线段存在初始重叠（最深约 8.24 mm）；真实设备初态尚无测量依据。6 s 自然沉降用于数值预处理，初始重叠及沉降过程逐步记录，不把这一段称为已验证的实机启动。正式验收要求沉降后的完整 10 s 观察满足原端点及接触范围判据。

`history/v2_rejection.json` 保留旧版完整制动的 10–24 mm 端点间隙及越界接触。该版四组完整结果、两组被替代的未完成细化和实际源码保存在独立拒收历史包；没有将它们标成六组通过。新版 32 N 受载诊断及回归只支持启动完整重跑，不代替六组验收。

交互沿用 B8 键盘和 B10 辅机电压/失电 API；新增 `release_cable_attachment(key)`，`key` 为 `supply_0..2`、`bond_PWR` 或 `bond_DAQ`。遥测包含辅机状态、线缆配置和端点间隙。

## 回放与依据

Blender 工程分别展示整车、供电线近景、柜门开关及接地线近景，另保留 B10 独立推定辅机启动试验台。所有线缆网格尺寸固定，父节点取数值求解姿态；中间插值属于显示。工程保存后重新打开，核对胶囊网格实际顶点的半径、端部范围和表面形状，并检查全部车辆、门件、线缆网格姿态与 B10 501 帧辅机轨迹。

- 源证据：`source_cables.json` 记录八条只读中心线、源 SHA-256、闭门参考及端点证据。
- [MuJoCo 3.3.7 XML reference](https://mujoco.readthedocs.io/en/3.3.7/XMLreference.html) 的 ball joint、stiffness、connect/site1/site2 支持被动关节及跨运动树连接的数值定义。它没有提供本项目线缆材料参数。
- B8 冻结覆盖矩阵和源机构审计保留为历史；本次只升级线缆等效模块，不将旧 22 工况计为本次全复测。

真实线缆/软管的自由长度、截面、质量密度、弯扭/拉伸曲线、接头位置/刚度、线槽接触和电气/流体功能尚需实测。无实测结构和时序数据时，本模块只能作为有明确假设的工程原型。
