# B12 可拆检修盖独立物理试验台

源模型四个可拆件成为有限质量自由刚体，固定时由可停用的六轴数值约束支承，解除后由重力、外加操作力、偏心力矩及地面接触求解位置和转动。输入是力或释放事件，没有指定升降位置、速度或旋转动画，也没有为源模型编造铰链。

**本版是单独的推定检修试验台。** 两块源 B5 盖板在恢复隐藏集合和骨骼评估后仍在世界原点，真实装配位置缺证据；另外两件的位置与形状也未实测。本版只复用可读源形状，四工位摆放、每件 0.25 kg 质量、均匀包围盒惯量、箱体接触和夹具参数均明确列为推定，不加入 B11 整车质量或安装反力。

## 物理边界

- 四个自由刚体，共 24 个广义速度坐标。每件以真实源 AABB 尺寸作碰撞代理，质量 0.25 kg；源鳍片网格保持外观，不作为逐鳍片接触或真实质量依据。
- 固定态为数值 weld，释放只停用约束，保留位置、线速度和角速度；没有 qpos/qvel 重置。
- 操作力通过 `apply_point_force(key, force_N, offset_from_com_world_m)` 输入。力臂叉乘产生实际力矩。输入非法时不改变状态或既有力。
- 机械能、外力功、全部约束功独立累计；线动量账本包括重力、外力与原生约束的冲量。角运动由有限惯量求解。
- 数值固定时间常数 0.5 ms、地面接触时间常数 1 ms、摩擦 0.4，均非实物标定。先前 2 ms 固定态试验未达到误差阈值，保存在 `history/fixture_2ms_trial.json`。

## 复现与验收

Python 3.12、MuJoCo 3.3.7、NumPy 2.2.6、Matplotlib 3.10.8；Blender 5.2 只作保存后的源网格回放。

```powershell
python source/vehicle-physics/b12/test_covers.py
python source/vehicle-physics/b12/simulate.py --case all
python source/vehicle-physics/b12/verify.py
python source/vehicle-physics/b12/report.py
```

五个完整 2 秒工况包括固定态、释放落下、落下半步长、偏心力提起后落下及操作半步长。自然释放时刻为 0.25 s；基准步长 50 µs，半步长 25 µs。5 项组件测试核对解析重力自由落体、源尺寸和均匀惯量、反力、偏心力转动、连续释放及非法输入。

128 项验收检查覆盖全时窗、机械残差 <0.005 J、动量残差 <1e-6 N·s、固定端间隙 <1e-5 m、最终落地静止、半步长接触峰变化 <5% 与最终高度差 <0.1 mm。允许软接触穿入低于最薄箱体代理厚度的一半；该阈值只限制本数值代理，不能解释为真实碰撞精度。

结果身份绑定每次实际力学源码、源几何 JSON、XML、CSV 和全部姿态帧的 SHA-256；运行起止检查源码没有变化。图中地面反力为 200 Hz 显示，峰值在全部积分步检查。有限质量和软接触生成的千牛峰不能当真实设备冲击载荷。

## Blender 交付

工程 `replay/assets/GTSD_BJTU_B12_cover_maintenance_bench.blend` 中 `B12_COVER_HANDLING` 展示偏心力提起与落下，`B12_COVER_DROP` 展示自然释放。源网格只跟随求解父刚体，显示布局和支架明确标注推定；支架网格不是额外碰撞定义。保存后重新打开，逐帧检查两组各 122 帧、四个刚体和四个源网格绑定，禁止表达式驱动。

完整 ZIP、逐文件大小/SHA-256/CRC 与新目录运行检查位于 `artifacts/B12/`。B8/B9/B10 的历史验收与独立交付保留，B11 的线缆耦合计算属于另一模块。

真实盖件质量/惯量、安装位姿、紧固件位置和拆卸动作、接触材料、与车体质量的归属均需外部结构图或实测。源 `source_properties` 已标明未核验尺寸和类比内部布局；本版没有把这些形状转述为实物结构证据。

数值固定/释放定义依据 [MuJoCo 3.3.7 的 weld 文档](https://mujoco.readthedocs.io/en/3.3.7/XMLreference.html#equality-weld)：world 为固定支承，运行时的 `eq_active` 可关闭约束。该文档说明数值约束含柔度，不能将其误称为真实螺栓机构。
