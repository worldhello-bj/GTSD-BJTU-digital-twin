# 照片默认装配：原生联动求解

默认模型把新照片道岔、两组应答器和两站接触网放在同一有限支承上。轮子由原生速度执行器驱动，真实经过接近轨、0.5 mm端接头、辙叉斜口、翼轨及右主轨。三支脉冲载荷同时经公共支承传递。

## 运行

在 `source/cad-source-console` 使用已配置的 MuJoCo 3.3.7 / NumPy 环境：

```sh
python operational_rig/server.py --port 8176
python -m unittest discover -s operational_rig/tests -v
python operational_rig/validate_protocol.py --output /tmp/gtsd-operational-check
```

控制台入口与实际启动参数由 `CONSOLE.md`（主线集成）说明。默认参数 `parameters.json`，每项单位和选择理由在 `parameter_sources.json`。所有质量、材料密度、刚度、阻尼、摩擦、接触正则化、完整销直径和完整索线基准位移均可修改并产生新模型身份。

## 几何、质量与力的同一归属

- 新照片区域的205个源网格全部保留对应显示绑定。实体轨、座、螺栓、螺母、垫片、底板和轨枕采用一个明确的刚接组，再通过Z向有限安装连接公共支承。
- 材料密度按钢、混凝土、聚合物和弹性体分别赋值。每个闭合物理实体由完整源三角形积分质量、质心及完整惯量，再按并轴定理汇总。
- 原轨头显示盖层位于完整钢轨内部，保留为 `visual_overlay` 别名；惯量与碰撞由完整钢轨承担一次。地面设备包络和固定背景为零动态质量的 `fixed_foundation`。
- 为让轮子从有轨支承处出发，新增0.3 m的 `OP_approach_` 完整源截面延长段。显示、惯量与碰撞使用相同完整实体；原照片轨件不改动。
- 轮子的规范实体为半径45 mm、宽12 mm的解析圆柱，惯量与碰撞均用解析实体；显示为同参数的192面内接网格，最大径向差6.024 µm。销轴完整直径变体和完整索线位移网格同时决定显示、惯量及碰撞。细分碰撞几何一律零质量。
- 轨顶碰撞由实际源顶三角形向实体内挤出1 mm形成凸棱柱，保留辙叉、槽口及端接缝边界。夹线槽使用实际源槽面的内向0.2 mm凸棱柱。接触边界没有额外平移或缩小。
- 两销轴与原孔/槽使用已验证的948凸分块。4.98 mm销直径是一项明确完整几何参数。
- 每站管、环、杆与常规紧固连接采用刚接等效；应答器壳体、盖板与螺钉同样刚接。有限安装弹簧及阻尼承接载荷。两销孔槽、轮轨和承力索/上下夹线槽保留实际原生接触。

默认轮轨接触响应时间为1.2 ms，两销与夹线为3 ms；轮轨较短的正则响应控制斜口着陆的数值穿透。

完整合同列出每个源网格的body、几何哈希、质量归属、每个碰撞geom的源网格及接口，以及所有有限安装参数。所有位姿来自MuJoCo，显示不放大运动。

## 当前验证结果

默认50 µs与25 µs的1.85 s完整通行均已完成，四段轨面与四类接口实际承载，检查点恢复完全一致。V3的14项协议门控通过12项：最大穿透81.32 µm、全程能量误差占比不超过0.169%、冲量差不超过0.272%、5 ms力差不超过3.773%。仍待解决的两项是着陆段轮位半步差143.127 µm及垂直速度差0.15218 m/s。完整报告见 `evidence/protocol_v3_failed.json`。

14项原生模型测试全部通过，包括18点接触A/B扫、分离证书、混合模块导入、双模型、未知模型过滤和恢复；含会话层的完整单元测试46项、真实DOM测试26项均通过。销端异常接触已修正，逐步几何复核已排除轨顶人工拼缝、人工底边与Newton迭代不足；当前定位真实尖角冲击的时间离散误差。

另有25/12.5 µs原生RK4的0.10 s共同初态筛选，位置与全部21DOF速度达到原门限；其四阶段力/功/冲量和完整通行尚未验证，因此所有局部原型均未替换当前V3。详见 `evidence/CONTACT_DIAGNOSTICS.md`。

构建合同中的 `contact_admission` 记录命名接触接口的接入条件；完整数值验收由协议的 `passed` 字段决定。

## 通行、能量与恢复协议

默认1.85 s程序：X速度目标0.8 m/s，100 ms余弦速度目标过渡；两应答器、两接触网站及承力索施加平滑力脉冲。导向轮保留自由Z运动与Y轴滚动，X方向采用原生速度执行器。Y导向是一项运动约束。1.85 s记录完整通行程序的终点；速度目标已降至零，轮子当时的余动仍原样保存在原生状态中。继续单步或运行会继续求解余动，不强制清零。

12 mm轮宽下辙叉到翼轨的潜在支撑投影间断为24.423310 mm，45 mm半径轮通过时存在真实下沉与接触切换。程序记录端接缝、辙叉/翼轨间断、鼻端及翼轨/右主轨四个位置事件。

协议比较50和25 µs完整程序，流式保存每步原生qpos/qvel、所有body位姿、实际输入、接触点/力/冲量和能量账。执行器功、外载功、安装阻尼耗散及原生接触约束功分别计数；接触点功与广义约束功独立核对。每案保存原生模型、身份合同、初末/事件快照以及精确恢复后的完整检查点。

参数表给的是工程选择及数值设置；源几何记录保留其CAD/照片来源。新身份独立于strict82/H1和旧research_rig，不替换它们的历史记录。

## 销端共面碰撞的定向修正

V2的25 µs轨迹在两个销轴/凸分块候选对产生了毫米级原生接触距离。对同一前积分姿态的完整凸SAT及编译后网格投影复核，两个候选对实际分别分离85.091和25.934 pm；源float64与编译float32顶点的量化差单独记录。

V3的模型专属接触筛选只排除已经证明严格分离的销轴/孔槽候选对：编译几何的共同Y轴投影间隙必须超过1 pm及保守浮点误差界之和。重叠和不确定边界继续进入原生碰撞与约束求解。18点双向微位移扫中，4个假深接触被排除，8个真实浅重叠接触逐字段保留。筛选代码参与模型身份；注册按原生模型隔离，恢复不引入额外可变状态。

MuJoCo 3.3.7的实际源码在广相阶段保留父子/焊接体筛选；本回调延续其掩码筛选。未知模型在父子默认、关闭父子筛选、焊接子体及两者组合四个测试中，完整接触点、法向与距离均保持一致。此结论由指定版本源码和运行测试共同核对。
