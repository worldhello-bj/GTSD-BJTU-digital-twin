# 独立轨本体源边界与交叠审阅

此补充不修改已验收支承 profile，不生成新轨道实装，也没有删掉任何未定长段。

## 可直接整合

- `rail_source_review.html`：完整离线查看页。57 条源线始终保留；“仅源线 / 直向关联 / 侧向关联”只改变突出显示。悬停显示 handle 和记录号。没有外部依赖。
- `native_track_curve_overlay.json`：57 条有限原生曲线，世界米制 XYZ，Z=0 仅表示CAD绘图平面，厚度/宽度为 null，零新增实装/物理身份。
- `native_edge_graph.json`：对应世界毫米源向量、原生行号、端点连接图。
- `complete_connection_review.json`：5 段双边明确的39.5 mm主轨头平面约束、6条细节链的有限端点/内部接点，以及未闭合区。
- `topology_candidate_fields.json`：最小拓扑候选的具体字段边界；默认仅源线，缺资料时禁止自动造实体或开槽。

57 是曲线数：44 条主/岔轨带边、6 条细节线、3 条连线、2 条端帽、2 条内接缝。它不是零件数。此前口头56少计了1条，冻结数据和查看页均用实际57。

## 发现与修正

不能只看 `4ED15` 后说主轨交会处没有另一条头边。主轨内侧水平头边还包括 `4ECED / 4ECEC / 4ECEB / 4ECEA`。x≈−8970 mm 的实际轨头重叠位于 `4ECED` 有限范围内，已有两条原生直轨头边，因此那里的重叠不是仅由“缺4ED15被全长外推”造成。

有限连接已逐项核对：

- `4ECED → 4ECFE` 在 (−8692.372752, 239.166667) mm 精确接点
- `4ECEC → 4ED02` 精确接点
- `4ECFA → 4ECEE` 精确接点
- `4ED5C` 另一端精确落在 `4ECED` 的有限边内部
- `4ED5D` 另一端精确落在 `4ECFE` 的有限边内部
- `4ECEA → 4ECE9 → 4ED2C` 连成开放链；4ED2C尾端没有已证实续接

不是只检查237轨图元子集。已查直接 Model 的2,738实体：解析1,464 LINE、441 LWPOLYLINE（包括bulge弧段）、230 ARC、255 CIRCLE的有限曲线；156 SPLINE控制包络及10 HATCH边界范围也不能在关键端点闭合。4ED2C开放尾端0.1 mm内没有别的曲线续接。`whole_model_connection_witness.json` 与 `native_curve_interior_witness.json` 给出证据、数量和方法限制。

57条全部是 `*Model_Space / ENTITIES / owner 1F` 的不同原生记录，没有 INSERT 投影变换，也没有正向/反向完全重复曲线。它们不是可随意删除的重复投影视图；但这个事实仍不能决定图纸是否叠画了工作状态，或交叉处哪些线属于同一制造件。

5段双边明确的直轨头平面约束保留。水平内侧头边之间的108.424 mm、2.667 mm、2.667 mm、3101.333 mm间断不等于同长度材料缺口。其间还存在斜边、曲线和未闭合细节，不能删去这些长段来获得“零碰撞”。

## 两类实际材料交叠不同

按当前 main 的实际默认显示几何作三角切片和面射线测量，数据见 `rail_layer_overlap.json`：

1. `inner_left_segment ↔ ENV_main_rail_1`：轨头 Z=−6.5 mm 有约39.5 mm 的最大采样Y材料弦；轨腰 Z=−35 mm约12.0 mm；轨底 Z=−61.5 mm约73.0 mm。其交叠贯穿轨头/轨腰/轨底，不能只“共用轨底”解决。
2. `guard_diverging ↔ CAD_TRACK_REV_outer_branch_native_xy`：Z=−61.5 mm轨底层的最大采样Y交叠弦约13.889 mm。实际三角面交线Z范围约−65.000至−55.295 mm。−6.5/−16/−35/−55 mm几个切片没有采到内部重叠，但不能将有限采样缺失冒充全域分离证明。

这些弦长是内部点处的实际材料区间，不是最小平移消穿量。X范围和最大值来自2,001个有限X样点，是采样观察，不是精确交集体积。原模型轨高/轨腰等Z截面仍是推定；护轨14/22 mm截面没有被独立源剖面确认。

## 最小拓扑候选的边界

可以讨论“共用下部支承＋独立原生顶面导向”的护轨方案，但必须决定护轨是共同固定件还是需要独立调整/拆换。没有这个决定，合并材料会偷偷改变维护和受力关系。

主轨/内侧岔轨的全轨头重叠则需要辙叉/尖端/轮缘通道的明确拓扑。仅选“直向”或“侧向”不能唯一决定工作导向面、闭合外轮廓、尖端范围、轮缘槽宽/深/侧别、收口长度及运动状态。源线15.333 mm的局部间距只是一条观察，未标成轮缘槽尺寸，不能拿来当默认槽宽。

因此最小可配置结果目前是3种**源边关联查看模式**，以及 `topology_candidate_fields.json` 中10项显式待定字段，所有几何参数保持null。既不自动删长段，也不把源图中的相交线直接布尔合并成实物。已有5段明确平面几何被完整保留；没有一个现在可唯一从源证据推导、又能解决全轨头交叠的实体patch。
