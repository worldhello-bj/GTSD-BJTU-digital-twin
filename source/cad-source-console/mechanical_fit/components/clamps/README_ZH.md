# 接触网夹具接口：可选择的源版本与安装候选

## 交付结论

基线为 main c5dd336 的实际默认源场景 `20_FRONT_ROUTE_NOMINAL_FIT`。已按控制台实际顺序应用旧解释排除表及323删326增的源替换，整机为1932件。没有修改基线文件或真实硬件。

这批资料不能唯一确定4079深度、F643横杆截面、孔心版本或固定方式。交付因此提供明确标识的工程候选，不把它们写成原图唯一修复或实装确认。

三个profile互斥，均只支持上述默认场景；其他四个场景或缺少任何精确remove_names时必须整组拒绝，不能半组应用。

- `clamp_fit_profile.json`：主夹具候选，6删6增。两根4079保留原三角形的全部Y/Z投影，只选择未被原图确定的X深度；两横杆替换为显式名义Ø5销；两B535细条选用8A2C的25 mm孔心版本。承力索不变。
- `clamp_messenger_datum_profile.json`：包含上述六件，再改选全长承力索槽心基准，7删7增。是独立附加审阅候选，不能与主profile叠加。端部卸扣、吊弦及固定方式未确认。
- `clamp_b535_review_profile.json`：B535原生25.837209302 mm孔心优先的对照候选，4删4增。销孔本身可配合，但与F643_profile_0产生新干涉，因此不能计为解决方案。

原始形状和位置保留在基线五个审阅场景及`published_clamp_meshes.json`。未裁环、未裁短杆、未缩小零件、未把真实源件直接隐藏来制造通过。没有新增物理碰撞体、刚体、质量或电气认证。

## 主候选改变了什么

### 4079

原生3BD17是开口5 mm带，3BD18/3BD19是同一图平面的端圆。原生没有证明Z向圆杆截面或世界X深度。它也不是5×5×30 mm顶杆的另一视图。

保留既有圆杆解释供工程审阅，仅将X置于当前局部障碍包络外。默认1 mm几何间隙是可调审阅参数，不是规范要求。两站候选深度改变量分别为+35.600019455、+35.600257874 mm，差异来自发布网格的Float32量化。全部源Y/Z顶点逐值相同。实际深度、上下固定方式仍为null；不能据此声称已经安装完毕。

### F643和B535

A3AD/3A9BA的原生40×5 mm投影保持为证据；旧统一4 mm拉伸深度没有源确认。新圆销是名义Ø5、40 mm长的工程解释，没有臆造螺栓头、螺纹、螺母或轴向固定。

主候选明确选择8A2C/3A99B隐藏投影的25 mm孔心，将B535/3A9A3的孔下移0.8372093023354 mm。B535外轮廓、厚度及Ø6孔径保持，未扩孔。孔心版本并不唯一；被替换的原生25.837209302 mm真圆孔版本完整保留。

若只把销上移到B535原孔而不处理关联轮廓，会对两站F643_profile_0新增10.823058、10.823154 mm³穿料。此反例有单独profile及报告，不会被“孔已对齐”掩盖。

## 实际三角网格前后结果

以下为发布Float32网格及最终读回候选的材料交叠体积，单位mm³。主候选解决六个枚举的非连接穿料接口：

| 接口 | 第一站修改前 | 第二站修改前 | 主候选修改后 |
|---|---:|---:|---:|
| 4079 / 上环 | 73.914373 | 73.914027 | 两站均0 |
| 4079 / 下夹块 | 66.654532 | 66.653422 | 两站均0 |
| 横杆 / B535细条 | 9.248174 | 9.246103 | 两站均0 |

两处销孔最小三角几何余量为0.499040、0.498925 mm。新销与F643_profile_0均无正体积交叠，但保持名义零余量接触，不是制造公差确认。两细条的顶舌/顶板槽配合仍为零正体积交叠。

上管与环的0.082239 mm轴偏差原本不构成干涉。实际管三角形裁剪至环宽后，其保守投影包络与环材料至少相隔0.416044 mm，因此上管和环完全未动。

承力索与两下颚的微穿料各为0.000106906 mm³。主候选故意保留这一未解决项。独立的索基准候选按槽心平移约0.100971 mm，保持实际线网格的直径和长度，两处微穿料变为0，最小几何余量约0.099421 mm。

## 保留并量化的连接界面

材料相交本身不能证明焊接、铰接或已完成固定。以下均保留为“连接方式待定”的材料界面，与需要间隙的非连接穿料分开计数：

- 4079下端/接触线：两站分别38.183680、38.183424 mm³，候选改深度前后相同，交点沿连续接触线平移。未裁短源Z端点，报告提供双方内部证点及世界位置。
- 主候选不动承力索，因此其端卸扣和七根吊弦连接完全不变。
- 独立索基准候选：两端卸扣材料交叠约39.001881/39.002065变为39.021378/39.021566 mm³；这不是已认证连接，也没有被算作已解决。
- 七根吊弦端交叠约0.640936–0.640945 mm³变为约0.000002981 mm³。剩余约0.238 μm量化接触仍按实际非零结果报告，未偷改为零。

`clamp_fit_validation.json`内before/after描述主方案；`optional_messenger_datum_after`才是全长索改位方案。请勿把可选方案的槽间隙数字归给主方案。

## 验证与复现

- 77项几何/接口/互斥选择检查通过；9项快速回归测试通过。
- 全部新增网格封闭、正体积、非退化；额外检查焊接顶点后的有向边一致性。
- 实体交叠使用实际三角帽面求交及分段积分，另用实网格固体角内部证点独立核验。端连接使用实际三角平面截线、自适应积分及内部点选择，报告包含数值误差估计。
- 1932件整机做AABB候选筛查；AABB只用于排除/筛选，绝未被当成穿料体积。
- 18条原生CAD记录已通过只读SQLite逐条复核。
- 在独立目录重新生成三个profile，与冻结文件逐字节相同。

依赖：Python 3.12、numpy 2.3.5、scipy 1.17.0，以及系统libgeos_c.so.1。无需Blender、第三方网格库或联网安装。生成器只读同目录输入、写同目录交付。

从本交付目录执行：

1. `python build_profiles.py`：按fit_config.json和已提取源网格重建三个候选。
2. `python verify_profiles.py`：重新执行完整实网格验证，约一分钟。
3. `python -m unittest test_profiles.py`：快速回归及冻结SHA验证。
4. 可选从当前控制台重新抽取：`node extract_published.js /path/to/cad-source-console`。该脚本接收显式源根目录，不含固定工作机路径。
5. 可选重核CAD：`python verify_native_source.py --native-sqlite /path/to/native_records.sqlite`。以只读URI打开。

`PROFILE_SHA256SUMS`用于冻结几何身份；`DELIVERY.json`列出应整合文件。未打包原始照片，未生成大渲染。本结果不代表整机、受力、预紧、制造公差、质量、电气或实物安装认证。
