## 实际材料检查结论

`build/material_audit.json` 对 9 个新设计实体逐一检查组合场景全部 1917 个未替换对象的包围盒，共 17,253 次筛选；任何潜在交叠都能在公开种子内找到，没有漏检对象。然后对 34 个正包围盒对做实际三角面切片与实体绕数筛选、积分，并记录内部材料见证点。

- 旧完整内轨与主轨的实际材料交集：**529,169.443080 mm³**。
- 9 个新设计实体两两没有超过数值阈值的交叠。采用所有三角面投影的保守体积上界，而非把 I 截面误当棱柱；最大数值余量为 **1.32×10⁻⁸ mm³**。
- **仍有 18 个保留对象冲突，不能称整装通过。**其中 17 个是扣件／紧固件，单对约 14.65–858.21 mm³；另一个是原左端短余段与辙叉轨底的 **0.488247685 mm³** 有限端接冲突。
- 这些实体、冲突和见证点均保留。原外侧护轨／岔轨轨底交叠也未被本修订解决。
- 不宣称轮缘可通过、全模型零碰撞、承载合格、安装固定方式正确或实物一致。

下一步需要决定每个扣件究竟归属哪个新翼轨／辙叉工作面，再做显式安装位姿或安装件候选；不能直接把当前重叠当成已确认的焊接／压接。有限左端接头也需单独决定，不自动裁短来消碰撞。

## 复建与测试

环境依赖：Python、NumPy、SciPy、Matplotlib、系统 GEOS C、Blender 4.3.2（验证版本）。没有新增软件安装，也不需要私有 CAD 数据库或照片。

```sh
OPENBLAS_NUM_THREADS=1 python build_candidate.py
OPENBLAS_NUM_THREADS=1 python audit_candidate.py
OPENBLAS_NUM_THREADS=1 python -m unittest -v test_candidate
MPLCONFIGDIR=build/cache OPENBLAS_NUM_THREADS=1 python render_overlay.py
python render_review.py
blender -b --factory-startup -t 1 --python render_native.py -- "$PWD"
```

`config.json` 可选 58、60、65 mm 的已验证可复建槽深。其他深度在当前 native 拓扑检查中尚未通过，构建器会拒绝，不能自动按默认值处理。修改配置须重新跑材料审计；60 mm 测试明确验证了底部交叠会重新出现。

13 项测试覆盖有限端点／方向、源截面、闭合正体积、数值级内部材料分离、独立支承层、远段原顶点保留、字节级重建、参数变化、非法隐式削薄模式和不掩盖冲突。原生布尔采用局部毫米坐标，数值焊接阈值 0.0001 mm；一个 1/3/3 边计数 T 接冗余细片在同一数值阈值内移除，详细证据保留。没有将数值修复伪装为工程间隙。

本目录是独立候选，未修改冻结工作树、未写远端、未打包、未接入求解器或正式 profile 选择器。
