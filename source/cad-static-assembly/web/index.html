操作与离线使用

  • 鼠标左键或单指拖动旋转；滚轮或 ＋／− 缩放；Home 复位。
  • 剖开壳体会隐藏被标记为 shell 的完整网格，不生成切面或修改几何。
  • WebGL 不可用时，仅投影同一批三角形。Canvas 回退使用逐像素 Z-buffer；最多 48 万像素、35 万三角形。当前整车415352面、全台架1256416面均超过此预算，请使用WebGL或Blender；Canvas可查看较小子系统。超限明确提示，不隐性减面。
  • 相对下载链接指向同包 outputs 文件夹，不上传或对外发布。
  • 从包根运行 python -m http.server 8000 后打开 /web/。本页只通过HTTP读取同包压缩几何；不上传、不连接硬件。
